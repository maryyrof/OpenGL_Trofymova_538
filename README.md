# Гра 2048 (C# + OpenGL)

## Опис
Практична робота з комп'ютерної графіки.
Реалізація числової головоломки 2048 з використанням бібліотеки OpenTK (OpenGL) на мові C#.

## Варіант
№6 — 2048 (Arcade/Puzzle), складність 2/10

## Реалізовані вимоги
- Ігрове поле 4×4
- Числові плитки зі значеннями 2, 4, 8, 16, 32, 64, 128, 256, 512, 1024, 2048
- Зсув плиток у 4 напрямки (стрілки ↑↓←→)
- Об'єднання однакових плиток
- Генерація нової плитки після кожного ходу
- Підрахунок рахунку (Score)
- Визначення досягнення плитки 2048 (YOU WIN!)
- Визначення стану Game Over

## Технології
- C#
- .NET Framework 4.8.1
- OpenTK 3.3.1 (OpenGL)
- Visual Studio 2026

## Як запустити
1. Відкрити рішення `Game2048.sln` у Visual Studio
2. Відновити пакети NuGet (OpenTK 3.3.1 встановиться автоматично)
3. Натиснути F5 для запуску

## Керування
- **↑ ↓ ← →** — рух плиток
- **R** — перезапуск гри
- **Escape** — вихід
